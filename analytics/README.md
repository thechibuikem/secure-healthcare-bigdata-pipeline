# Reports in /marts

## condition_prevalence
**Question:** how common is each condition, by age band?
**Output:** DESCRIPTION (condition name), age_band, patient_count

## encounter_volume
**Question:** how many visits happened each month?
**Output:** month (YYYY-MM), encounter_count

## medication_trend
**Question:** which medications are prescribed most often?
**Output:** DESCRIPTION (medication name), prescription_count
